# GDIS Dubai — "星系" 概念官网原型

单页 3D 网站：迪拜（GDIS）是恒星/引力中心，中国与阿拉伯世界是同一轨道上的两颗行星，
两条光粒子流双向流动（中→阿、阿→中），四项服务是绕行的卫星，200+ 投资机构组成外围星系。
滚动页面时镜头依次飞到：首屏 → 使命（双向通道）→ 服务（卫星）→ 网络（星系）→ 联系。

- 中文 / English / العربية 三语切换（阿语自动 RTL）
- Three.js 已放在 `vendor/`，不依赖任何 CDN 和 Google 字体（国内可直接访问）
- 纹理全部程序生成，无图片素材；不支持 WebGL 时退化为渐变背景

本地预览：`cd gdis && python3 -m http.server` 然后打开 http://localhost:8000
部署：把整个 `gdis/` 目录上传到任意静态托管即可（Cloudflare Pages / Vercel / 阿里云 OSS 等）。
